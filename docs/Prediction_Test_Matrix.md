# Prediction_Test_Matrix — матрица тестов ПР №4 (игра bob_arena, Godot 4.7.2)

Условия: реальный UDP на localhost, два процесса (хост — Listen Server, клиент под управлением скрипта), эмуляция сети в приложении на исходящем
трафике каждой стороны (задержка «в одну сторону», RTT ≈ 2×). Профили: **100 мс, 0% потерь** и **175±25 мс, 4% потерь** (в допустимом задании
диапазоне 150–200 мс и 3–5%). Прогон: `.\run_godot_demo.ps1 -Role Scenarios` (или `GODOT=... tools/game_scenarios.sh`), сводка — `python tools/game_report.py`.
Числа ниже — из `docs/game_runs/` (последний прогон; в скобках разброс по трём прогонам). Артефакты — логи, графики, видео, скриншоты.
