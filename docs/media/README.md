# docs/media — артефакты ПР №4

Три файла с именами из задания — **графики по логам реального прогона Godot-версии** (не видео и не скриншоты окна
игры: прогон шёл в headless-режиме без экрана). Они строятся скриптом `tools/godot_report.py` из логов
`docs/godot/runs/*.log`, которые, в свою очередь, пишет `tools/godot_scenarios.sh` (Listen Server + бот-клиент по
реальному ENet на localhost).

| Файл | Что показывает | Сценарий |
|---|---|---|
| `baseline_no_prediction.png` | рывок **без** предсказания: реакция на экране приходит только после ответа сервера (≈ RTT) | T2, lag 100 мс |
| `prediction_enabled.png` | рывок **с** предсказанием: локальный отклик сразу, подтверждение сервера — позже | T3, lag 100 мс |
| `correction_example.png` | намеренное расхождение (чит клиента): отказ сервера, коррекции, возврат к серверной позиции | T5, lag 175±25 мс, 4% потерь |

Если преподавателю нужно именно **видео экрана**, его можно записать вручную: `.\run_godot_demo.ps1 -Godot "<путь>" -Role Both
-Profile lag100 -Predict 0`, затем то же с `-Predict 1`, и `-Profile lag175loss4` + клавиша `F1` (чит) для третьего ролика.
Видео в репозиторий не добавлено — если оно будет во внешнем хранилище, ссылку и время ключевого момента укажите в
`docs/Prediction_Implementation.md`. Для варианта на Unreal Engine те же три материала нужно снять в самом UE
(см. `docs/Prediction_Test_Matrix.md`, часть B).
