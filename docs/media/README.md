Графики строит `tools/game_report.py` из `docs/game_runs/*.log` (реальный UDP, два процесса).
Видео и скриншоты записаны в режиме **виртуального времени** (`tools/game_video.sh`: хост и клиент в одном процессе поверх `LoopHub`,
Godot Movie Maker, кадры синхронны с симуляцией) — логика та же, что по UDP, но запись не зависит от скорости рендеринга и загрузки процессора.

## Как записать видео с настоящим UDP между двумя окнами (Windows 11)

```powershell
.\run_godot_demo.ps1 -Role Scenario -Case T3 -Viz 3     # хост + клиент с окнами; клиентом управляет скрипт
```
Перед запуском включите запись экрана (Win+Alt+R или OBS) и снимайте окно клиента. Сценарии: `T2` — без предсказания, `T3` — с предсказанием,
`T5` — чит и коррекция. Вручную (клавиатурой): `.\run_godot_demo.ps1 -Role Both -Profile lag100 -Predict 0|1 -Viz 3`, в игре **F4** — предсказание рывка,
**F8** — режим визуализации, **F3** — net_graph; чит — запуск с `-DebugKeys` (`--debug`) и F10.
